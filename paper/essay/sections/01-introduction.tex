\section{Introduction}\label{sec:intro}
This report documents a distributed brute-force attack that recovers the
authentication key protecting RIPv2 routing updates captured in a controlled
lab. RIPv2 supports a keyed message-digest authentication mode
(RFC~2082~\cite{rfc2082}); the captures use six-character keys. We first
reverse-engineer the exact digest construction from a packet capture
(\autoref{sec:reveng}), then build a master--worker cluster that partitions the
key\-space across TCP-connected workers (\autoref{sec:protocol},
\autoref{sec:partition}), tolerates node failure (\autoref{sec:death}), and we
characterize its throughput (\autoref{sec:bench}).
